# เริ่มใช้งาน BN9 X Social Real V6 Easy Ready

คู่มือนี้สำหรับคนที่ไม่รู้โค้ด ให้ทำตามลำดับนี้

## 1. เปิดโปรแกรม

ดับเบิลคลิก `START_HERE.bat`

ถ้าโปรแกรมบอกว่ายังไม่มี dependency ให้ดับเบิลคลิก `FIX_INSTALL.bat` ก่อน แล้วกลับมากด `START_HERE.bat` อีกครั้ง

## 2. กด Health Check

ในแท็บ `0 Start Here` กด `Health Check`

ระบบจะเช็กเครื่อง, library, `.env`, token และโฟลเดอร์ `outputs` แบบ offline โดยไม่ยิง X API จริง

## 3. ใส่ App Bearer Token

ไปที่แท็บ `1 ตั้งค่า`

ใส่ `App Bearer Token = อ่านข้อมูลสาธารณะ` แล้วกด `บันทึกค่า`

ระบบจะบันทึกทั้ง `APP_BEARER_TOKEN` และ `BEARER_TOKEN` เพื่อให้ไฟล์เก่าของ V5 ยังใช้ได้

## 4. ทดสอบอ่านข้อมูล

ใช้ปุ่มทดสอบแบบอ่านข้อมูลเท่านั้น เช่น `ทดสอบ Bearer ด้วย Usage API`

ถ้า token ยังไม่พร้อม ให้ดูข้อความ error ภาษาไทยและแก้ตามที่ระบบบอก

## 5. เช็กจำนวนก่อนดึง

ไปแท็บ `2 Social Listening`

ใส่คำค้น แล้วกด `1 เช็กจำนวนก่อนดึง`

## 6. ดู Cost Estimate

ก่อนกด `2 ดึงจริง + วิเคราะห์ + รายงาน` ระบบจะแสดงจำนวนโพสต์โดยประมาณและจำนวนครั้งที่คาดว่าจะเรียก API

ถ้าจำนวนสูงเกินไป ให้ลด `ดึงสูงสุด/คำค้น` หรือจำนวนคำค้นก่อน

## 7. ดึงจริง + วิเคราะห์ + รายงาน

เมื่อยืนยันแล้ว โปรแกรมจะดึงข้อมูล วิเคราะห์ และสร้างรายงานใน `outputs`

เปิดรายงานได้จากปุ่ม `เปิด Dashboard ล่าสุด`

## 8. ถ้าจะ Reply/Like/DM ค่อยทำ User Token

Action จริง เช่น Post, Reply, Like, Follow, DM ต้องใช้ `User Access Token`

ก่อนยิง Action จริง ระบบจะทำขั้นตอน `Preview -> Queue -> Confirm -> Execute` และบันทึก audit ไว้ที่ `outputs/action_audit.jsonl`

ห้ามส่ง token ให้ผู้อื่น และห้ามแคปหน้าจอที่เห็น token
